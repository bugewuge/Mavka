## ✨ Можливості

- 🎵 **Медіа-контроль** — плеєр із керуванням треками прямо з вікна MAVKA.
- ⚡ **Швидкі дії** — скріншот, запис екрана, палітра кольорів, QR-коди (створення та зчитування).
- 🧩 **Віджети** — привітання, годинник і дата, погода, стан Wi-Fi та Bluetooth, гучність.
- ⭐ **Улюблені додатки** — запуск потрібних програм в один клік.
- 🧚 **Персонажі з української міфології** — Мавка, Лісовик, Перелесник та інші.
- 🇺🇦 **Повністю українською**, без реклами та підписок.

## 💻 Встановлення

1. Завантажте інсталятор (`.exe`) з [останнього релізу](https://github.com/bugewuge/Mavka/releases/latest).
2. Запустіть його та дотримуйтесь підказок.
3. Відкрийте MAVKA з меню «Пуск» — і користуйтесь.

**Системні вимоги:** Windows 10 або Windows 11 (x64).

> ⚠️ Якщо Windows SmartScreen показує попередження — натисніть «Докладніше» → «Все одно виконати».
